# Agents, Tools, and Skills

F30 separates responsibility from capability. Agents own workflow roles. Skills encode reusable governance reasoning procedures. Tools provide deterministic operations. The orchestrator controls sequencing and the human authority gate.

## Agents
Governance Intake, Policy and Charter, Risk and Controls, Board Process, Evidence Auditor.

## Skills
Authority mapping, governance risk review, evidence gap analysis.

## Tools
Document normalization and decision-record construction. Reference tools are deterministic and side-effect free.
