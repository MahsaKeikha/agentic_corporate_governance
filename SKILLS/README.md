# F30 Skills

The executable reusable governance skills live in [`src/skills/`](../src/skills/).

Core capabilities include authority mapping, governance risk assessment, evidence-gap analysis, decision-process preparation, and traceable governance reasoning.

Skills are reusable procedures that may be shared by multiple agents. They remain distinct from tools and from the agents that select them.

See [`src/skills/domain_skills.py`](../src/skills/domain_skills.py).
