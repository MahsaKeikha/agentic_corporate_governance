# Security Policy

Do not place confidential board materials, credentials, personal data, privileged legal material, or production secrets in public examples or issues.

Report suspected vulnerabilities privately through GitHub's security reporting mechanisms when available. Include affected version, reproduction steps, impact, and suggested mitigation if known.

This reference implementation does not provide an authorization boundary for production corporate systems. Deployers are responsible for authentication, authorization, encryption, secret management, logging, retention, privacy, dependency review, model/provider security, and organization-specific threat modeling.
