# Contributing

Contributions should improve reproducibility, architecture clarity, evidence integrity, evaluation, security, or domain realism.

For behavior changes, add or update tests. Preserve the F30 result contract and fail-closed human authority gate. Do not add fabricated benchmarks, unsupported production-readiness claims, or examples containing confidential governance information.

Recommended pull requests include: problem statement, architectural rationale, tests/evaluation evidence, security or governance implications, and documentation changes.
